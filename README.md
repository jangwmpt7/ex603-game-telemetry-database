# ex603-game-telemetry-database

Name: Jack Nguyen

Theme: Game Telemetry

## Description

This project will exhibit an example of a game telemetry database that collects, analyzes, and utilizes data of a video game about the players, the matches, and the participants (including, but not limited, to the aforementioned players), the game and match modes, and the scoreboard for each match (mainly upon their conclusion).
